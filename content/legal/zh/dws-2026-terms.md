欢迎各位参加 Develop with Solar Network 2026 特别活动。
本条款旨在明确 Solsynth、参赛者（以下简称「您」）等各方的权利和义务，保证活动顺利进行。

## 1. 协议的接受和使用范围

当您提交作品 / 投票参与本活动时，
勾选「我已阅读并同意相关条款」时即为接受本协议与协议后续的更新版本。
若任何一次的协议更新的内容让您认为想要撤销同意，请删除您相关提交的项目和作品或撤销您的投票。

若您不同意本协议，请不要参与本活动或在活动页面参与任何内容。

本协议从接受日开始生效，在活动结束后仍然保留效力。

## 2. 参赛资格

- 任何人均可参与本活动，无年龄、地域限制。
- 使用自动化脚本注册、手动注册多个账号的行为将被导致参与资格审查，轻则取消本次活动的奖品和资格，重则封禁 Solarpass 账号。

## 3. 知识产权

参赛者保留其提交作品的全部权利。
提交即表示您授予 Solsynth 有限的许可，以展示、分享和推广您的参赛作品用于竞赛相关目的。
您的项目不需要开源，但必须公开源代码（源代码必须可公开访问）。

## 4. 行为准则

参赛作品必须遵守适用法律法规，并符合以下要求：

- 不得包含恶意软件、病毒、木马、后门、间谍软件或任何其他有害代码。
- 不得利用参赛作品进行网络攻击、数据窃取、欺诈、钓鱼或其他任何非法活动。
- 不得包含侵犯他人知识产权、隐私权、肖像权或其他合法权益的内容。
- 不得包含色情、暴力、仇恨言论、歧视性内容或其他违反社会公序良俗的内容。
- 不得绕过、破坏或试图破坏 Solar Network 或其相关服务的安全性、完整性或正常运行。

任何违反上述条款的行为将导致立即取消参赛资格，并可能承担相应的法律责任。

## 5. Solar Network 开发者条款

由于参赛作品需要使用 Solar Network 的 API 或服务，参赛者在开发前必须阅读并同意 [Solar Network 开发者条款](/legal/solar-network-dev)。
该条款规定了 API 的使用限制、数据使用规范、速率限制以及其他开发者必须遵守的规则。
参赛者有责任确保其参赛作品符合 Solar Network 开发者条款的所有要求。
违反开发者条款可能导致 API 访问权限被撤销，参赛作品将无法正常运行。

## 6. 取消资格

Solsynth 有权在以下情况下取消参赛者的资格：

- 违反本协议的任何条款。
- 提交的作品不符合参赛要求或被发现包含违法、有害内容。
- 通过作弊、欺诈或其他不正当手段获取投票或优势。
- 任何评委或管理员认定的不当行为。

取消资格后，相关作品将从活动中移除，获奖者将从候补中递补。

## 7. 奖品

奖品设置及发放方式由 Solsynth 另行公布。
奖品不可转让、不可兑换现金。如遇不可抗力导致奖品无法发放，Solsynth 有权以等值替代品发放。

## 8. 责任免除

Solsynth 对参赛作品的内容、功能、安全性不作任何担保。
参赛作品由其创建者自行承担全部责任。
Solsynth 不对因使用或无法使用参赛作品而导致的任何直接或间接损失负责。
Solsynth 对活动期间的服务中断、数据丢失或其他技术问题不承担责任，但将尽力修复和恢复。
